# Evidencias de Formación - ADSO | SENA

Repositorio destinado al almacenamiento y organización de las evidencias, actividades,
talleres y proyectos desarrollados durante el programa de formación:

**Análisis y Desarrollo de Software (ADSO)** del **Servicio Nacional de Aprendizaje (SENA)**.

---

## Sobre el repositorio

Este repositorio contiene las actividades y evidencias desarrolladas durante el proceso
de formación en el programa ADSO.

El objetivo es mantener organizados los diferentes trabajos realizados a lo largo de la
formación, permitiendo consultar el proceso de aprendizaje, los ejercicios desarrollados
y los proyectos construidos.

Los contenidos se irán incorporando progresivamente a medida que avance el programa.

---
